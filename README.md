# effect_city

A simulated city for exercising Effect services: grid, zones, economy, population, and telemetry.

TypeScript, Effect, Vite, React, and Three.js. Architecture playground, not a finished game.

## Run

```sh
bun install
bun run dev
```

CLI slices:

```sh
bun run demo:simulation
bun run demo:population
bun run demo:economy
bun run demo:zone
```
